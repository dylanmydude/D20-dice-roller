# Terminal D20 roller

**Requirements:** Ruby installed on your computer.

## Setup:
- Clone

## Run file:

    alias roll="python3 /your_clone_folder/d20_dice/dice_roller.py" 

## Run using alias:

    sudo nano ~/.bashrc

and add the follwing to your bash file:
    
    alias roll="python3 /home/dylan/python/d20_dice/dice_roller.py" 

Run the file by typing "roll" in your terminal
